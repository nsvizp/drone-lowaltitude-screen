# 演示视频录制脚本（约 4 分钟 · 一镜到底）

> 录制前准备：
> 1. 双端启动：`./scripts/start-dev.sh`（确认 backend/frontend 均 ok）
> 2. 浏览器开 http://127.0.0.1:5173，分辨率 1920×1080，登录 admin / Admin@2026
> 3. 录屏工具：系统自带（Cmd+Shift+5）或 OBS；关闭通知
> 4. 若上一场演练有残留，先点「✅ 结束演练」清场

## 录制要点

- **节奏**：AI 推演约 40 秒是天然的"解说窗口"，不剪辑正好念完解说词
- **库存扣减**：空投瞬间盯住右侧仓储进度条（演示亮点）
- **增援时机**：「建议二次调配」约在下达后 1~2 分钟出现（水位三连涨触发），耐心等待别快进
- **失败预案**：若增援未触发，直接跳过第 8 镜——链路完整性不受影响
- **备录素材**：shots/ 下有全部关键画面截图可补镜
